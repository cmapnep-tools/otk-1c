# Лицензии 1С

Что из ОТК работает без лицензии 1С, что её требует и как с ОТК работает лицензия для разработчиков. Источник —
руководство администратора 8.3.27 (раздел 1.6.3.6 и глава 10, ИТС); сколько лицензий нужно для правомерного
использования — по [ответам 1С](https://v8.1c.ru/predpriyatie/questions_licence.htm) и условиям вашего договора.

## Что нужно для запуска

| Ступень | Проверки | Запуск платформы | Лицензия 1С |
| --- | --- | --- | --- |
| Статика | метаданные и ссылки, анализаторы BSL, методы и типы платформы | нет: справка читается из файлов `.hbk` установленной платформы или из готового индекса, таблицы доступности — в пакете | **не нужна** |
| Пробы в копии ИБ | компиляция (сервер, внешнее соединение, тонкий клиент), разбор запросов, расширенная проверка, формы, сценарии, `designer-check`, отрицательный контроль | пакетный Конфигуратор, тонкий клиент, внешнее соединение (COM) | клиентская |

**Статика** (`otk gate --static-only`) не запускает платформу, поэтому работает в контейнере и на облачных раннерах
CI. Устанавливать платформу в образ не нужно: достаточно индекса справки, который ОТК один раз строит из справки
вашей платформы (`otk platform-help build`); он лежит в кэше (`OTK_CACHE`) и копируется в образ. Без индекса статика тоже
работает, но проверка методов платформы получит «не проверено». Анализатору BSL LS индекса мало: правила по
событиям (сигнатуры и области обработчиков) он берёт из `shcntx_ru.hbk` — копию файла положите в
`environment.helpDir`, иначе эти правила не работают (примечание в сводке). Проверено на Windows с платформой,
скрытой от процесса, и на Linux без платформы (WSL2, Ubuntu 24.04, Python 3.12, BSL LS 1.0.7 для Linux): тот же
результат, что на Windows; в контейнере Docker — ещё нет.

**Пробы** запускают клиентские приложения 1С. Однопользовательская программная лицензия позволяет запускать на
одном компьютере произвольное количество клиентских приложений и конфигураторов (10.3.1.2, 10.3.4.2), поэтому
для своей файловой копии ИБ достаточно лицензии на компьютере, где идёт проверка.

**Раннер CI как служба Windows.** Клиентское приложение, запущенное из службы ОС, система лицензирования считает
аналогом терминального сервера: для него нужна дополнительная лицензия, и это касается любых программных
лицензий (10.3.4.9). Раннер, запущенный в сеансе пользователя, — обычное рабочее место.

## Лицензия для разработчиков (community)

Бесплатная лицензия для платформы 8.3.23 и новее, только программная; активируется на портале
[developer.1c.ru](https://developer.1c.ru) (1.6.3.6, 10.3.6; [новость 1С](https://1c.ru/news/info.jsp?id=30506)).
На Linux пункт активации показывается только при доступе к `users.v8.1c.ru` и с настройками `conf.cfg` — что
проверить, в [linux.md](linux.md#лицензия-для-разработчиков).

**Коммерческое использование ею не разрешено**: платформа с активированной лицензией для разработчиков не может
использоваться в коммерческих системах. Для некоммерческого проекта она подходит; что считается коммерческим
использованием в вашем случае (проверка кода заказчика, CI организации) — по лицензионному соглашению портала,
которое показывается при активации. ОТК об этом не судит и лицензию не проверяет.

Ограничения, важные для ОТК:

| Ограничение (1.6.3.6, 10.3.6) | Что значит для ОТК |
| --- | --- |
| Используется, только если на компьютере нет другой лицензии (для файловой ИБ — базовой, ПРОФ или КОРП) | на машине с обычной лицензией ОТК работает под ней |
| Одновременно — 1 клиентский и 1 серверный компьютер; на одну учётную запись — не больше 3 компьютеров | компьютер разработчика и раннер CI одновременно под одной лицензией не работают |
| Срок действия — неделя, продлевается автоматически через интернет; нет доступа к ресурсам 1С — лицензия перестаёт действовать | раннеру CI нужен выход в интернет к ресурсам 1С; изолированный раннер — не вариант |
| Не больше 3 сеансов с прямым подключением к одной ИБ | одному прогону ОТК хватает (см. ниже); параллельных прогонов в одну копию ИБ ОТК не запускает: занятая копия — сбой окружения (код 2) |
| Не больше одного рабочего сервера в кластере | своя копия ИБ ОТК — файловая, ограничение её не касается |
| Собирается статистика использования механизмов платформы (без данных ИБ) и передаётся в 1С | — |

**ОТК разработан и проверен под лицензией для разработчиков**: другой лицензии на машине разработки нет, поэтому
все прогоны — `gate` с пробами в копии ИБ, `designer-check`, `controls --parity`, дымовой тест форм, задания CI
на той же машине (раннер в сеансе пользователя, не службой; платформы 8.3.27 и 8.5.1) — шли под ней; прогоны на Linux (WSL2, 8.3.27) — под отдельной активацией той же учётной записи.
