# Настройки (`otk.toml` / `otk.local.toml`)

Приоритет: аргументы командной строки ([«Только командная строка»](commands.md#только-командная-строка)) >
переменные `OTK_*` > `otk.local.toml` > `otk.toml` > умолчания. Переменная переопределяет настройку проекта под
себя (своя платформа, своя копия ИБ); что взято из переменных, показывает `otk doctor`. Неизвестный раздел или
ключ (опечатка) — предупреждение в `doctor` и в примечаниях сводки.
Образец со всеми ключами — [otk.example.toml](../otk.example.toml).

| Переменная | Ключ |
| --- | --- |
| `OTK_IB`, `OTK_USER`, `OTK_PASSWORD` | `environment.ib`, `user`, `password` |
| `OTK_PLATFORM`, `OTK_COM`, `OTK_IB_TOOL` | `environment.platform`, `comConnector`, `ibTool` |
| `OTK_YAXUNIT`, `OTK_EDTCLI` | `environment.yaxunit`, `edtcli` |
| `OTK_BSLLS`, `OTK_BSL_ANALYZER` | `environment.bslls`, `bslAnalyzer` |
| `OTK_RUN_DIR`, `OTK_HIDDEN_DESKTOP` | `environment.runDir`, `hiddenDesktop` (`0`, `false`, `no` — ложь) |

Без ключа в настройках: `OTK_CACHE` — кэш ОТК (справка платформы, таблицы доступности), `OTK_BASES` — файл баз
`otk console`.

## Словарь имён платформы

Статика знает методы, типы и системные перечисления платформы по справке синтакс-помощника. Имена, которых в
справке нет, а Конфигуратор их принимает, и стандартные имена объектов метаданных лежат во встроенном словаре
[`platform-names.toml`](../src/otk_1c/availability/platform-names.toml):

| Ключ | Что | Проверка |
| --- | --- | --- |
| `methods` | метод без точки (устаревшие методы, которые платформа поддерживает) | `platform-api` |
| `constructors` | тип в `Новый Тип` | `platform-api` |
| `globals` | имя перед точкой (`Имя.Значение`): системные перечисления и значения | `platform-api`, «Переменная не определена» |
| `forms` | стандартная форма объекта (`ФормаСписка`) | `form-name` |
| `managerMethods` | начало имени стандартного метода менеджера (`Создать`, `ПустаяСсылка`) | `manager-method` |

Ложная находка на имени, которое платформа принимает (например, после обновления платформы), — допишите имя в
раздел `[platformNames]` своего `otk.toml` или `otk.local.toml`, не дожидаясь выпуска ОТК. Списки объединяются
со встроенными, регистр не важен, русское и английское имя — отдельными строками:

```toml
[platformNames]
globals = ["НовоеСистемноеПеречисление", "NewSystemEnum"]
```

Неизвестный ключ или значение не списком — примечание в сводке, раздел не применяется, прогон продолжается.

## Уровень находок анализаторов

Новое замечание анализатора BSL (проверка `analyzers`) — ошибка, если его правило во встроенном списке
(`ParseError`, `ProcedureReturnsValue`, `UnknownPreprocessorSymbol`, `ThisObjectAssign` — у обоих анализаторов),
остальные — предупреждения ([«Находки»](findings.md)). Новая версия анализатора может переименовать правило или
добавить своё — поправьте список разделом `[analyzerSeverity]`, не дожидаясь выпуска ОТК. Для каждого анализатора
(`bslls` — BSL LS, `bsl-analyzer`) `error` добавляет правила к ошибкам, `warning` снимает их до предупреждений; имя
правила — как в находке после двоеточия, с учётом регистра:

```toml
[analyzerSeverity]
bslls = { error = ["UsingModalWindows"] }
bsl-analyzer = { error = ["UnresolvedMethodCall"], warning = ["ThisObjectAssign"] }
```

Набор правил, которые анализатор вообще проверяет, задаёт его конфигурация (`.bsl-language-server.json`,
`bsl-analyzer.toml`), а не этот раздел. Неизвестный анализатор или ключ, значение не списком, одно правило и в
`error`, и в `warning` — примечание в сводке, раздел не применяется, прогон продолжается.

## Расширения

Для проекта-расширения задайте `source` (выгрузка расширения) и `parent` (выгрузка основной
конфигурации); расширение и его имя распознаются по Configuration.xml выгрузки (`extension` — только чтобы
переопределить имя). Без `parent` ссылки на основную конфигурацию не проверить — такие находки статики
понижаются до предупреждений. Модули расширения пробуются в копии ИБ с расширением;
расширенная проверка — `/CheckModules … -ExtendedModulesCheck -Extension <имя>` самого расширения
(на небольшом расширении — секунды). Для небольших расширений удобен `gate --all`.
