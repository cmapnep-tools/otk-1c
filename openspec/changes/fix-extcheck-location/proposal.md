# Точная позиция замечаний extcheck

## Why
Рост кратности одинаковых сообщений доказывает новую ошибку, но не её конкретное текстовое вхождение. Поиск первого упоминания идентификатора приписывает ошибку старому коду или комментарию.

## What Changes
- Сохранять отсутствие строки, когда платформа не сообщила позицию.
- Различать доказанную новизну по кратности и недоступное сравнение режима.
- Сохранять точные позиции платформы.

## Impact
Меняются только результаты сравнения extended-check и регрессионные тесты; зависимости не добавляются.

## Context sources
Подтверждено: extended_check.compare, _new_findings и тесты test_extcheck_forms.py. Живой запуск платформы не требуется для проверки алгоритма сравнения и не выполнялся.
