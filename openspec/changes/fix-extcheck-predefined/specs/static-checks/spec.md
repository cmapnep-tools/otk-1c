## ADDED Requirements

### Requirement: Предопределённые данные временного расширения

Расширенная проверка SHALL включать предопределённые элементы непосредственно заимствованных объектов
основной конфигурации в допустимом формате расширения, сохраняя их имена, id и вложенность.
Для каждого элемента SHALL использоваться `ExtensionState=AdoptedCheck`.

#### Scenario: Корректное имя и опечатка

- **WHEN** основная конфигурация содержит предопределённый элемент `Standard` каталога `SampleKinds`,
  а проверяемый модуль обращается к `Справочники.SampleKinds.Standard` и `Справочники.SampleKinds.Standrad`
- **THEN** временное расширение содержит заимствованный `Standard`, платформа не предупреждает о `Standard`
  и диагностирует `Standrad`

#### Scenario: Вложенные элементы

- **WHEN** предопределённый элемент расположен внутри предопределённой группы
- **THEN** расширение сохраняет и группу, и элемент, их id и связь родителя с потомком

#### Scenario: Оболочка зависимости по типу

- **WHEN** объект заимствован только как оболочка зависимости по типу
- **THEN** его предопределённые данные не переносятся

#### Scenario: Исходный файл недоступен для чтения

- **WHEN** предопределённые данные заимствуемого объекта есть, но файл нельзя прочитать
- **THEN** шаг сообщает ошибку инфраструктуры с путём файла и причиной
