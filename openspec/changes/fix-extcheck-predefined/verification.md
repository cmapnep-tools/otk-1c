# Проверка

## Платформа

1С 8.3.27.2342, новая пустая файловая ИБ вне рабочих каталогов. Основная конфигурация — локальный
синтетический демопример, предопределённое имя заменено на `Standard`. Общий серверный модуль расширения:

```bsl
Процедура Тест() Экспорт
    А = Справочники.Номенклатура.Standard;
КонецПроцедуры
```

Расширение строилось непосредственно `adopted_object` → `generate_test_extension` из изменённого кода.
После `/LoadConfigFromFiles … -Extension otk` выполнялся `/CheckModules` с режимами `check_modes(False)`.

| Имя | Загрузка расширения | Проверка модулей |
| --- | --- | --- |
| `Standard` | rc=0 | rc=0, «Синтаксических ошибок не обнаружено!» |
| `Standrad` | rc=0 | rc=101, «Возможно ошибочное свойство: "Standrad"» |

Повторная выгрузка расширения сохранила исходный id предопределённого элемента и
`ExtensionState=AdoptedCheck`. Отдельная частичная выгрузка основной конфигурации с
`-listFile` (`Catalog.Номенклатура`) включила `Catalogs/Номенклатура/Ext/Predefined.xml`:
добавлять отдельный адрес файла в ветвь исходников EDT не требуется.

Контроль причины перед исправлением: без Predefined.xml платформа предупреждала и о корректном имени,
и об опечатке. Простое копирование платформа принимала, но при выгрузке добавляла `AdoptedCheck`.
Значение `Adopted` не принималось загрузкой; реализация явно генерирует подтверждённый `AdoptedCheck`.

## Ограничения

Платформенный контроль выполнен на 8.3.27.2342 для справочника. Вложенность проверена unit-тестом;
старые платформы, планы счетов/видов характеристик и полный экспорт проекта EDT отдельно не запускались.
Новые зависимости не добавлялись; рабочие ИБ не использовались.
