# Проверенная граница платформенной диагностики

В новой пустой файловой ИБ создан серверный общий модуль. Проверка на 8.3.23.2236:
`/CheckModules -Server -ExternalConnection -ExtendedModulesCheck`.

```bsl
Процедура Проверить() Экспорт
    Данные = Новый Структура("Флаг", Истина);
    Данные.Свойство("Флаг", ОТКВыходнойНеОбъявлен);
КонецПроцедуры
```

| Вариант | Код возврата | Результат |
| --- | --- | --- |
| Код выше | 101 | Переменная не определена (ОТКВыходнойНеОбъявлен), строка 3, оба контекста |
| Перед созданием структуры: `Перем ОТКВыходнойНеОбъявлен;` | 0 | Синтаксических ошибок не обнаружено |
| Перед созданием структуры: `ОТКВыходнойНеОбъявлен = Неопределено;` | 0 | Синтаксических ошибок не обнаружено |

Платформа принимает присваивание как определение переменной, но не объявляет переменную при передаче
выходного аргумента. Контроль каталога закрепляет отдельный случай; он не приписывает сторонним
анализаторам гарантии, которой каталог ранее не проверял.

Правило по тексту `.Свойство(...)` не добавляется: одноимённый метод динамического объекта не доказывает
тип получателя, а переменные формы и модуля не сводятся к поиску присваивания в текущем методе.
Полный gate уже использует платформенные пробы. `--static-only` остаётся быстрым ограниченным режимом.
