# Контроль необъявленного выходного аргумента (#53)

## Why
Платформа 8.3.23.2236 отвергает `Данные.Свойство("Флаг", ОТКВыходнойНеОбъявлен)` при локальном `Данные = Новый Структура(...)`. Отсутствие находок статического анализа не доказывает компилируемость такого кода.

## What Changes
Добавить отдельный контрольный дефект с ожиданием платформенных проверок COM и extcheck. Описать границу `--static-only`. Не вводить эвристику по имени динамического метода: без определения типа и области видимости она может отвергать корректный код.

## Impact
Каталог controls, документация проверок, тесты формирования дефекта. Полная проверка уже включает платформенные пробы; обязательность шагов не меняется.

## Context sources
- `openspec/project.md`, `openspec/specs/control-defects/spec.md`, `src/otk_1c/extras/controls.py`.
- Изолированная новая ИБ, платформа 8.3.23.2236: `/CheckModules -Server -ExternalConnection -ExtendedModulesCheck` возвращает 101 для необъявленного аргумента, 0 после `Перем` и предварительного присваивания.
- Другие версии платформы и исчерпывающая семантика динамических методов не проверялись.
