# Design

## Формат файлов расширения

Конфигуратор не загружает выгрузку, в которой файлы разных версий формата, и не грузит файлы новее платформы
(«Неизвестная версия формата»). Поэтому версия файлов ОТК — не константа, а функция источника:

| Источник | Версия формата |
| --- | --- |
| выгрузка Конфигуратора | `version` корня `Configuration.xml` |
| исходники EDT | максимальная версия формата платформы проверки (таблица ИТС) |
| потолок генерации | 2.20 |

Таблица платформы (`ib_tools._PLATFORM_FORMATS`): 8.3.21 → 2.14, 8.3.22 → 2.15, 8.3.23 → 2.16, 8.3.24 → 2.17,
8.3.25 → 2.18, 8.3.26 → 2.19, 8.3.27 → 2.20, 8.5.1 → 2.22. Потолок 2.20: столько ОТК проверяет на 8.3.27 и
8.5.1; для 8.5.1 выгрузка 2.22 новее — генерация всё равно 2.20, и это загружается.

`Form.xml` заимствованной формы пишется в версии остальных файлов расширения: иначе Конфигуратор отвечает
«отличается от версии формата ранее загруженных файлов».

Ранняя ошибка: если выгрузка новее платформы (2.20, платформа 8.3.23), копию ИБ загрузить нельзя — `require_format`
даёт `InfraError(code="format-unsupported")` до сборки, с понятным текстом.

## Полный сбой проверки

Расширенная проверка возвращает `(результаты, примечание)`. Не выполнилась целиком — модуль `extended_check`
бросает `Failed(reason)`, `ExtCheck.run` переводит это в `ctx.gate.failed("extcheck", reason)`: `on` — сбой
инфраструктуры (код 2), `auto` — «не проверено» с `check: extcheck`. Per-module `skipped` не выдаются: они
описывают частичный результат, а не отсутствие проверки.

Полный сбой: расширение не загрузилось; `/CheckModules` вернул ошибку без разобранных строк; не удалось получить
выгрузку/экспорт для заимствования (`designer_root`).

`reasonCode` для «Неизвестная версия формата» и «формат выгрузки … новее» — `format-unsupported`, иначе
`reasons.classify` вернул бы `other`.
