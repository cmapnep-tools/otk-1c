## ADDED Requirements

### Requirement: Заимствование объектов по типам реквизитов

Кроме объектов, на которые модули ссылаются через менеджеры, временное расширение extcheck SHALL заимствовать
объекты основной конфигурации, на которые ссылаются типы реквизитов, измерений, ресурсов, табличных частей и
общих реквизитов заимствуемых объектов (`<v8:Type>` и `<v8:TypeSet>`, в исходниках EDT — `<types>`), включая
составные типы: без заимствованного объекта платформа не загружает расширение целиком
(«Неизвестное имя типа - CatalogRef.Items»), и проверка не выполняется. Типы в описаниях заимствованных объектов
SHALL сохраняться как есть: удалять или подменять тип ради обхода ошибки загрузки нельзя.

Зависимости по типам SHALL собираться транзитивно, до замыкания; повтор и цикл SHALL сниматься ключом
«коллекция + имя без учёта регистра». Зависимость по типу SHALL заимствоваться оболочкой — только сам объект, без
реквизитов, табличных частей, значений перечисления и свойств (общие реквизиты): расширению нужен сам тип.
Свойства-типы оболочки (определяемый тип, тип значений характеристик) SHALL заимствоваться по тому же правилу —
иначе оболочка определяемого типа не загружается. Объекты, заимствованные ради модулей и ссылок через менеджеры,
SHALL по-прежнему получать реквизиты: на них ловится опечатка в поле.

Признак «с табличными частями» SHALL сохраняться и в сборе зависимостей: у объекта, заимствованного без ТЧ
(ссылка через менеджер, общий реквизит), типы реквизитов его ТЧ в набор не входят; у владельца изменённого модуля
объект заимствуется с ТЧ — входят. Сборка расширения и частичная выгрузка ИБ SHALL давать один и тот же набор.

Частичная выгрузка ИБ для исходников EDT (вместо экспорта сборки) SHALL содержать тот же набор объектов по типам,
собранный теми же двумя фазами: полный объект — все свои типы, оболочка — только свой тип.

#### Scenario: Составной тип реквизита

- **WHEN** заимствованный справочник имеет реквизит с типами `CatalogRef.Товары` и `DefinedType.Основание`
- **THEN** в расширении есть `Справочник.Товары` и `ОпределяемыйТип.Основание` — оболочками, без реквизитов

#### Scenario: Цепочка и цикл определяемых типов

- **WHEN** `DefinedType.Основание` включает `DefinedType.Второй`, а `Второй` — `Основание`
- **THEN** замыкание завершается, каждый определяемый тип заимствован один раз, состав каждого разрешается

#### Scenario: Исходники EDT без экспорта сборки

- **WHEN** расширенная проверка идёт по частичной выгрузке ИБ и у заимствованного объекта есть реквизит типа
  `DefinedType.Основание`
- **THEN** `-listFile` выгрузки содержит и этот определяемый тип, и объекты его состава

#### Scenario: Только XML-ссылка, без кода

- **WHEN** правка не добавляет обращений в модулях, а тип реквизита изменённого объекта ссылается на
  незаимствованный объект
- **THEN** объект заимствуется, расширение загружается, `notChecked` не содержит `extcheck`
