# Неизменяемая редакция для gate --head

## Why

`gate --head HEAD` строит план из Git blob, но отдельные шаги читают файлы рабочего дерева, если SHA плана равен текущему HEAD. Незакоммиченные правки могут изменить фактически проверенный код и текст находки без изменения плана.

## What Changes

- Все чтения исходников явной Git-редакции используют один снимок по `headSha`, включая `HEAD` и случай с грязным рабочим деревом.
- `--worktree` продолжает проверять снимок индекса и отслеживаемых файлов через `git stash create`; неотслеживаемые файлы остаются вне плана.
- План, статика, пробы, сборка и строки отчёта относятся к одной редакции; для ошибок материализации результат инфраструктурный, без зелёного вердикта.

## Context sources

Подтверждено кодом: `collect.collect` читает Git blob, `workspace.tree_root` и `pipeline.static_step` переходят к рабочему дереву при SHA текущего HEAD. Проверка на платформе 1С не выполнялась: контракт источника проверяется синтетическим Git-репозиторием.
