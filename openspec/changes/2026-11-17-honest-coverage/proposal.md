# Вердикт по фактически выполненным проверкам

## Why

Наличие пустого `static.json` сейчас считается проверкой. Изменение одних метаданных не запускает статический шаг, но может получить код 0. Так зелёный результат не подтверждает проверку изменённого входа.

## What Changes

- Учитывать только подтверждённые выполненные проверки, а не наличие файла результата.
- Передавать изменения метаданных в применимый статический шаг; пустой или пропущенный шаг не даёт покрытия.
- Для непустого плана без выполненных проверок возвращать код 2 и «ничего не проверено», для действительно пустого diff сохранять код 0.

## Context sources

Подтверждено кодом: `pipeline.gate_run` не вызывает `_probe_step` для metadata-only, `report.checked_count` считает любой `static.json`, `report.verdict` не включает метаданные в условие непустого ввода. Поведение платформы 1С не проверялось.
