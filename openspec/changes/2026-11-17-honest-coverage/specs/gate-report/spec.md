## ADDED Requirements

### Requirement: Учёт фактических проверок непустого плана

Проверка SHALL засчитываться только по свидетельству фактической работы над входом плана;
существование пустого файла шага или запись о пропуске проверкой не являются. Непустой план включает модули,
запросы, сценарии, дымовые тесты, удалённые модули и изменения метаданных.

#### Scenario: Пустой файл статического шага

- **WHEN** в плане есть изменённый модуль, а `static.json` записан без фактически выполненной проверки и пробы пропущены
- **THEN** код выхода 2 с сообщением «ничего не проверено»

#### Scenario: Удалён только локальный метод

- **WHEN** у изменённого модуля удалён только неэкспортный метод и в HEAD нет изменённых строк для правил статики
- **THEN** статический шаг не засчитывает этот модуль как проверенный

#### Scenario: Удалён экспортный метод без изменённых строк HEAD

- **WHEN** у общего модуля, неглобального и в BASE, и в HEAD, удалён экспортный метод, а в HEAD нет изменённых строк для правил статики
- **THEN** после поиска зависимых вызовов статический шаг засчитывает этот модуль как проверенный

#### Scenario: Удалён экспорт глобального общего модуля

- **WHEN** у глобального общего модуля удалён экспортный метод или весь модуль, а проверка не ищет вызовы без имени модуля
- **THEN** поиск зависимых вызовов сам по себе не засчитывает этот модуль как проверенный

#### Scenario: Общий модуль перестал быть глобальным при удалении экспорта

- **WHEN** экспортный метод удалён одновременно со сменой флага Global с true на false
- **THEN** поиск только квалифицированных вызовов сам по себе не засчитывает удаление как проверенное

#### Scenario: Флаг Global заимствованного модуля неизвестен

- **WHEN** отсутствует основная конфигурация с флагами заимствованного общего модуля
- **THEN** поиск только квалифицированных вызовов сам по себе не засчитывает удаление экспорта как проверенное

#### Scenario: Общий модуль переименован при удалении экспорта

- **WHEN** модуль переименован и из него удалён экспортный метод
- **THEN** поиск зависимых вызовов по новому имени модуля сам по себе не засчитывает удаление как проверенное

#### Scenario: Изменены только метаданные

- **WHEN** изменён только XML объекта, а подходящий статический шаг не выполнил проверку
- **THEN** код выхода 2 с сообщением «ничего не проверено»; при выполненной проверке вердикт определяется её результатом

#### Scenario: Выбран только сценарий

- **WHEN** план содержит только сценарий и его выполнение пропущено
- **THEN** код выхода 2 с сообщением «ничего не проверено»

#### Scenario: Пустой diff

- **WHEN** план не содержит изменённых входов и ничего не проверялось
- **THEN** код выхода 0 с вердиктом «нечего проверять»

#### Scenario: Ничего не проверено и не покрыт обязательный контекст

- **WHEN** непустой план не получил ни одной фактической проверки и обязательный контекст остался без покрытия
- **THEN** код выхода 2, а вердикт сообщает и «ничего не проверено», и имя непокрытого обязательного контекста
